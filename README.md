## 🚀 Featured Projects

Here is a curated selection of systems I have engineered. Comprehensive architectural overviews and technical details are available in my public project portfolio.

### 🛡️ [PassGuard — Password Security Microservice](https://github.com/kassiis/project-portfolio/blob/main/projects/Passguard.md)
A modular Python microservice providing multi-layer credential defense: real-time entropy and dictionary analysis, cryptographically secure password and Diceware generation, RFC 6238 TOTP two-factor authentication, Argon2id hashing, and privacy-preserving breached credential checking via the Have I Been Pwned k-anonymity model.  
*(Source code: Private repository)*

### 📊 [SEC_LAB — Real-time Linux Telemetry System](https://github.com/kassiis/project-portfolio/blob/main/projects/SEC-LAB.md)
A zero-dependency Go daemon and interactive web dashboard engineered for cybersecurity laboratory environments. Gathers kernel metrics directly from the Linux `/proc` virtual filesystem using non-blocking delta calculations and stores bounded historical samples in a preallocated circular ring buffer.  
*(Source code: Private repository)*

### 🧠 [Cybersecurity ML & Intrusion Detection](https://github.com/kassiis/project-portfolio/blob/main/projects/Cybersecurity-ML.md)
An empirical evaluation suite comparing supervised ensemble classifiers (Random Forest, AdaBoost, Gradient Boosting) and unsupervised clustering techniques on the UNSW-NB15 network intrusion benchmark.  
*(Source code: Private repository)*

### 🕷️ [Algerian Web Scraper & Crawler](https://github.com/kassiis/project-portfolio/blob/main/projects/DZ-Web-Scraper.md)
A high-throughput Python data extraction engine powered by Scrapling, featuring autonomous site navigation with cycle detection, structured table extraction, and verification of Algerian `.dz` ccTLD records, telephone numbering plans, and commercial registries.  
*(Source code: Private repository)*
